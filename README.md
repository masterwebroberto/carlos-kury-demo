# Carlos Kury — Demo para revisión

Sitio estático HTML/CSS/JS sin compilación. Abrir con un servidor HTTP local.

## Estado

- Cinco páginas: Inicio, Biografía, Música y Videos, Contacto y Privacidad (borrador).
- Spotify y YouTube se cargan al solicitar reproducción; requieren conexión y disponibilidad del proveedor.
- Intro animada: una vez por sesión, con opción de omitir y respeto al movimiento reducido.
- Formspree sin endpoint, aprobación en falso y envío deshabilitado. No activar hasta aprobar y publicar la política.
- Demo marcada noindex/nofollow; esto no restringe el acceso público.
- Fotografías, textos y enlaces se conservan para revisión del artista. Redes y teléfono pendientes siguen identificados como tales.

## Publicación prevista (requiere autorización)

Crear repositorio público carlos-kury-demo, subir estos archivos a main y configurar GitHub Pages desde la rama main y carpeta raíz. No requiere Actions ni claves. .nojekyll evita procesamiento Jekyll. Las rutas relativas permiten publicar bajo /carlos-kury-demo/.

## Alcance público

Solo se incluye el sitio y sus recursos; no se incluyen historiales, scripts anteriores ni informes internos de la carpeta original. La licencia OFL de Inter se conserva en assets/fonts/OFL.txt. No se concede una licencia nueva sobre fotografías o música.
